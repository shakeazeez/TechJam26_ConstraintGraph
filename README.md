# ConstraintGraph

ConstraintGraph is a local, stateful conversational product-retrieval agent for the TechJam 2026 Shopping Copilot challenge.

The implementation will combine catalog-derived constraint signatures, conversational state management, exact matching, and lightweight lexical retrieval. It is designed to run reproducibly without a paid LLM API.

Development has not started yet. The implementation plan is intentionally kept local and excluded from Git until it has been reviewed.
